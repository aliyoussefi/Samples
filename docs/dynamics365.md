# Dynamics 365
{: .no_toc }

Samples for extending Microsoft Dynamics 365 / Dataverse — client-side scripting, server-side plug-ins, the Web API, and admin tooling.
{: .fs-5 .fw-300 }

[Open the Dynamics365 folder on GitHub](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365){: .btn .btn-primary }

| Sample | Description |
|:--|:--|
| [Alerts](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/Alerts) | Alerting samples for Dynamics 365. |
| [Client](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/Client) | Client-side scripting samples (form and ribbon/command logic). |
| [In-App Notifications](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/In-AppNotifications) | Send in-app notifications in model-driven apps, including an Azure Function trigger. |
| [SDK](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/SDK) | Organization Service / SDK samples. |
| [Side Panes](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/SidePanes) | App side pane (`Xrm.App.sidePanes`) samples. |
| [Solution Checker](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/SolutionChecker) | Solution Checker automation samples. |
| [Web API](https://github.com/aliyoussefi/Samples/tree/main/Dynamics365/WebApi) | Dataverse Web API samples with a Postman collection. |

{: .tip }
> Many of these samples use the `@types/xrm` typings (see the repo `package.json`) for IntelliSense against the Xrm client API.
