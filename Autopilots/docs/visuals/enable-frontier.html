Enable Microsoft Scout Frontier

Six things to do before users sign in.

Scout installs easily, but sign-in only works after the organization gate, device gate, attestation, and Copilot entitlement are all in place.

Enablement steps

Clear actions for admins.

Work these in order. The longest lead times are usually Frontier propagation, GitHub Copilot licensing, and Intune policy sync.

01

Enroll in the Frontier program

Join the Copilot Frontier preview program and accept the participation terms for the organization.

  • Use a tenant admin or organization decision maker.
  • Confirm the tenant is eligible for Frontier previews.
02

Turn on Copilot Frontier

In the Microsoft 365 admin center, open Copilot settings and enable Copilot Frontier for all users or a selected pilot group.

  • Save the setting.
  • Allow up to about three hours for propagation.
03

Submit the attestation

Complete the Frontier organization sign-up or attestation form because Scout can route data to third-party inference paths.

  • Use the current form link from Microsoft Learn.
  • Keep evidence that the opt-in was submitted.
04

Assign GitHub Copilot

Each user needs a GitHub account with GitHub Copilot Business or Enterprise entitlement.

  • Individual Copilot is not enough.
  • Confirm the GitHub Copilot app policy is enabled.
05

Deploy the Intune policy

Import the Scout policy template and enable Microsoft Scout Frontier access on managed devices.

  • Use Imported Administrative Templates.
  • Validate the registry value after device sync.
06

Validate sign-in

Install Scout, sign in with the user’s Microsoft 365 work account and GitHub identity, then confirm there is no org or waitlist block.

  • Use troubleshooting if sign-in is blocked.
  • Check both gates before changing the device.
