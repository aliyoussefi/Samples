# Information Technology persona pack

This persona pack shows how Microsoft Scout can act as an always-on IT chief of staff. The goal is to make IT leaders more productive by watching stakeholder asks, IT operations, identity, endpoint, SaaS, security, calendar, and project signals, then turning scattered work into prioritized, approval-ready follow-through.

---

## Value proposition

Software-company IT leaders lose time when operational signals are spread across Outlook, Teams, tickets, device tools, identity systems, SaaS admin portals, vendor emails, budget trackers, and executive meetings. Scout helps by acting as a user-facing chief of staff that:

- surfaces urgent IT asks, escalations, and blockers that need attention now
- prepares leaders for security, budget, vendor, roadmap, and executive meetings
- tracks stale incidents, access blockers, onboarding gaps, and unresolved commitments
- drafts stakeholder updates, owner reminders, operating briefs, and meeting prep notes
- identifies repeat issues that should become templates, automation, or self-service guidance
- keeps the human in control before anything is sent, changed, approved, or updated

Scout is productivity support for keeping employees productive, systems reliable, security posture visible, SaaS spend controlled, and cross-functional IT commitments moving.

---

## Common IT systems and work surfaces

These samples are designed to fit software companies that use tools such as:

- Communications: Outlook, Teams, calendar, meeting transcripts
- IT service management: ServiceNow, Jira Service Management, Zendesk, Freshservice
- Identity and access: Microsoft Entra ID, Okta, Ping, Active Directory
- Endpoint management: Microsoft Intune, Defender for Endpoint, Jamf, Kandji
- Security and compliance: Microsoft Defender XDR, Sentinel, Wiz, CrowdStrike, Vanta, Drata, ServiceNow GRC
- SaaS, finance, and vendor management: Zylo, Productiv, Coupa, NetSuite, Workday, Excel, Power BI
- Planning and notes: OneNote, Planner, SharePoint, OneDrive, Loop

The prompt should only use systems the user is authorized to access.

## Persona: Director of IT

**Job to be done:** Keep employees productive, systems reliable, security follow-through visible, SaaS spend controlled, and cross-functional IT commitments moving.

**Scout value:** Scout watches Outlook, Teams, calendar, tickets, endpoint posture, identity and access signals, SaaS and vendor threads, project trackers, and unresolved commitments. It surfaces the few IT actions that need attention now and prepares approval-ready updates, checklists, briefs, and draft responses.
